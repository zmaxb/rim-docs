# Документация РИМ

Документация расширения **РИМ** для `1С:Предприятие` — платформы интеграции
мессенджеров и автоматизации ботов.

Основной раздел документации находится в [docs/index.md](docs/index.md).

## Локальный запуск

Установите зависимости:

```bash
pip install mkdocs-material pymdown-extensions
```

Запустите локальный сервер:

```bash
mkdocs serve
```

После запуска документация будет доступна по адресу:

`http://127.0.0.1:8000/`

Проверка сборки:

```bash
mkdocs build --strict
```

## Структура

- `docs/getting-started` — установка и запуск демонстрационных ботов;
- `docs/bots` — создание и настройка ботов и моделей бота;
- `docs/integrations` — архитектура и разработка интеграций.

Некоторые разделы находятся в разработке.
