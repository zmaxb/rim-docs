# Создание интеграции

Интеграция мессенджера определяет, как РИМ подключается к внешнему сервису, получает входящие события и отправляет сообщения.

Каждая интеграция должна содержать:

- справочник параметров бота;
- вид мессенджера в перечислении `рим_ВидыМессенджеров`;
- общий модуль провайдера интеграции;
- регистрацию справочника параметров в механизмах РИМ.

В этом разделе рассмотрим устройство интеграции Telegram и на её примере разберём, что необходимо реализовать для подключения другого мессенджера.

## Справочник параметров бота

Каждая интеграция должна быть представлена отдельным справочником, в котором хранятся параметры подключения ботов.

В интеграции Telegram для этого используется справочник:

```text
рим_ПараметрыБотовTelegram
```

При создании новой интеграции его можно скопировать и использовать как основу.

После копирования можно удалить реквизиты, относящиеся только к Telegram. При этом необходимо сохранить обязательные реквизиты, используемые механизмами РИМ:

```text
ТипИнтеграции
ПрофильДлительногоОпроса
Подключение
ПрофильHTTP
```

Остальные реквизиты определяются разработчиком интеграции и зависят от требований конкретного мессенджера.

Например, интеграция может содержать токен, идентификатор приложения или другие данные, необходимые для взаимодействия с внешним сервисом.

Интерфейс формы элемента справочника определяется разработчиком интеграции. При этом форма должна обеспечивать возможность изменения всех обязательных реквизитов.

После создания справочника его тип необходимо добавить в состав определяемого типа:

```text
рим_ПараметрыБота
```

После этого элементы созданного справочника смогут использоваться в поле **Параметры бота** карточки бота.

## Вид мессенджера

Добавьте новый вид мессенджера в перечисление:

```text
рим_ВидыМессенджеров
```

Например, для интеграции нового мессенджера добавьте значение:

```text
НовыйМессенджер
```

Это значение используется при выборе параметров бота и регистрации менеджера
справочника параметров для новой интеграции.

## Провайдер интеграции

Каждая интеграция должна иметь собственный общий модуль, который реализует взаимодействие между РИМ и конкретным мессенджером.

Для Telegram используется общий модуль:

```text
рим_БотПровайдерTelegram
```

При создании новой интеграции этот модуль можно использовать как пример.

Общий модуль может содержать дополнительные методы и реализации, необходимые конкретной интеграции. При этом он обязательно должен реализовывать все методы, расположенные в области:

```text
#Область ИнтерфейсРИМ
```

Эти методы образуют контракт между РИМ и интеграцией.

Их реализация позволяет РИМ использовать провайдер для получения входящих событий, их обработки и отправки исходящих сообщений.

## Регистрация параметров интеграции

Для подключения созданного справочника параметров необходимо расширить функцию `МодульМенеджераПараметровБота`, расположенную в модуле расширения:

```text
рим_БотыМессенджеров
```

Функция возвращает менеджер справочника параметров бота для указанного вида мессенджера.

```bsl
// Возвращает менеджер справочника параметров бота для указанного вида мессенджера
//
// Параметры:
//   ВидМессенджера - ПеречислениеСсылка.рим_ВидыМессенджеров
//
// Возвращаемое значение:
//   СправочникМенеджер - менеджер справочника параметров бота
//
Функция МодульМенеджераПараметровБота(ВидМессенджера) Экспорт

	Если ВидМессенджера = Перечисления.рим_ВидыМессенджеров.Telegram Тогда
		Возврат Справочники.рим_ПараметрыБотовTelegram;
	ИначеЕсли ВидМессенджера = Перечисления.рим_ВидыМессенджеров.ВКонтакте Тогда
		Возврат Справочники.рим_ПараметрыБотовВКонтакте;
	Иначе
		ВызватьИсключение(
			НСтр("ru = 'Неопределен вид мессенджера'"));
	КонецЕсли;

КонецФункции
```

В функцию необходимо добавить условие для нового вида мессенджера и вернуть менеджер созданного справочника параметров.

Например:

```bsl
ИначеЕсли ВидМессенджера =
	Перечисления.рим_ВидыМессенджеров.НовыйМессенджер Тогда

	Возврат Справочники.рим_ПараметрыБотовНовогоМессенджера;
```

После этого РИМ сможет определить, какой справочник параметров необходимо использовать для выбранного вида мессенджера.

## Поддерживаемые способы подключения

В настоящее время для новых интеграций поддерживается подключение в режиме **Long polling**.

В этом режиме РИМ самостоятельно обращается к сервису мессенджера и запрашивает новые события.

Поддержка режима **Webhook** пока доступна только для интеграции Telegram.

Возможность использования Webhook в других интеграциях находится в разработке.

## Итог

Для создания новой интеграции необходимо:

- создать справочник параметров бота с обязательными реквизитами;
- добавить его тип в состав определяемого типа `рим_ПараметрыБота`;
- добавить вид мессенджера в перечисление `рим_ВидыМессенджеров`;
- реализовать общий модуль провайдера с методами области `ИнтерфейсРИМ`;
- зарегистрировать менеджер справочника параметров в функции `МодульМенеджераПараметровБота`.

После выполнения этих шагов РИМ сможет использовать новую интеграцию для подключения ботов, получения входящих событий и отправки сообщений через поддерживаемый мессенджер.
