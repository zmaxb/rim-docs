# 🚀 Быстрый старт

Инструкция позволяет выполнить базовую настройку РИМ и запустить демонстрационного Telegram-бота.

!!! tip "Что потребуется"

    Для настройки потребуются:

    - сообщество ВКонтакте с включёнными сообщениями;
    - ключ доступа сообщества;
    - идентификатор сообщества.

    Порядок создания и настройки сообщества описан в разделе
    [Подготовка сообщества ВКонтакте](ссылка).

## 🤖 Создание демонстрационного бота

Бот содержит прикладную логику обработки входящих запросов и определяет, как система должна реагировать на сообщения, команды и другие события мессенджера.

!!! info "Демонстрационный бот"

    РИМ не включает готовых ботов для промышленного использования, однако содержит демонстрационного бота, который можно использовать для проверки работы системы.

### 1️⃣ Создание бота

Откройте справочник `Боты мессенджеров` в подсистеме `Интеграция мессенджеров`.

Начните создание нового бота и заполните:

- **Наименование** — произвольное имя
- **Параметры бота** — выберите параметры `Telegram` (необходимо создать новый элемент)
- **Модель** — выберите `Предопределённый бот (демонстрационный)`

[![Создание бота](../img/bot-create.png)](../img/bot-create.png)

---

### 2️⃣ Настройка параметров

Создайте параметры для нового бота.

Заполните:

- **Наименование** — произвольное имя
- **Токен** — токен Telegram-бота, полученный через [BotFather](https://telegram.me/BotFather)

После заполнения сохраните изменения.

[![Параметры бота](../img/telegram-params.png)](../img/telegram-params.png)

Для проверки корректности настроек выполните команду `Проверить подключение`.

При успешном подключении отобразится окно с информацией о боте.

Созданные параметры укажите в поле **Параметры бота** при настройке бота.

---

### 3️⃣ Проверка бота

После выбора параметров запишите нового бота.

После записи в списке ботов в колонке **Состояние обработки** должно отображаться значение `Выполняется`.

[![Состояние обработки](../img/bot-status.png)](../img/bot-status.png)

Это означает, что бот готов к обработке входящих сообщений и отправке ответов.

Затем откройте Telegram, начните чат с ботом и отправьте любое сообщение.

!!! success "Проверка работы бота выполнена"
