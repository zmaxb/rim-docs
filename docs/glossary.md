# Глоссарий

## РИМ

**РИМ** — расширение для `1С:Предприятие`, которое обеспечивает интеграцию с
мессенджерами и автоматизацию ботов. РИМ управляет обработкой запросов,
очередями, сессиями, аутентификацией, доступом и отправкой сообщений.

См. также: [Введение](index.md).

## Интеграционный механизм РИМ

**Интеграционный механизм РИМ** — общая подсистема, которая принимает события
из мессенджеров, передаёт их моделям ботов и отправляет сформированные
ответы обратно в мессенджер.

См. также: [Введение: Интеграции](integrations/index.md).

## Интеграция мессенджера

**Интеграция мессенджера** — реализация взаимодействия РИМ с API конкретной
платформы, например Telegram или ВКонтакте. Она получает внешние события,
приводит их к внутреннему формату РИМ и отправляет исходящие сообщения.

См. также: [Архитектура решения](integrations/architecture.md).

## Вид мессенджера

**Вид мессенджера** — значение перечисления `рим_ВидыМессенджеров`, которое
определяет поддерживаемый мессенджер и используется при регистрации новой
интеграции.

См. также: [Создание интеграции](integrations/create-integration.md).

## Провайдер интеграции

**Провайдер интеграции** — общий модуль 1С, который реализует программный
контракт между РИМ и конкретным мессенджером.

См. также: [Создание интеграции](integrations/create-integration.md).

## Бот

**Бот** — конкретный рабочий экземпляр, который связывает модель бота,
параметры интеграции, способ доступа и другие настройки.

См. также: [Введение: Боты](bots/index.md).

## Модель бота

**Модель бота** — реализация прикладной логики. Она обрабатывает входящие
запросы, команды и события, использует данные контекста и формирует исходящие
сообщения.

Одна модель бота может использоваться несколькими ботами, в том числе в разных
мессенджерах.

См. также: [Создание модели бота](bots/create-model.md).

## Параметры бота

**Параметры бота** — настройки подключения конкретного бота к интеграции
мессенджера. Обычно они содержат тип интеграции, способ подключения и данные
доступа к API мессенджера.

См. также: [Создание бота](bots/create-bot.md).

## Общие настройки

**Общие настройки** — набор параметров, который может использоваться несколькими
ботами и позволяет не дублировать одинаковые значения в их карточках.

См. также: [Создание бота](bots/create-bot.md).

## Входящий запрос

**Входящий запрос** — внутреннее представление события, полученного из
мессенджера. РИМ записывает входящий запрос в очередь, подготавливает контекст,
проверяет доступ и при необходимости передаёт запрос модели бота.

См. также: [Архитектура решения](integrations/architecture.md).

## Исходящее сообщение

**Исходящее сообщение** — сообщение, сформированное РИМ или моделью бота для
отправки пользователю через интеграцию мессенджера.

См. также: [Архитектура решения](integrations/architecture.md).

## Очередь входящих запросов

**Очередь входящих запросов** — хранилище запросов, полученных от
мессенджеров. Отдельный механизм выбирает записи из очереди и запускает их
обработку.

См. также: [Архитектура решения](integrations/architecture.md).

## Очередь сообщений к отправке

**Очередь сообщений к отправке** — хранилище исходящих сообщений, ожидающих
отправки. Отдельный обработчик передаёт сообщения интеграции и фиксирует
результат отправки.

См. также: [Архитектура решения](integrations/architecture.md).

## Контекст выполнения

**Контекст выполнения** — набор данных об окружении обработки: боте, его
настройках, адресате и параметрах выполнения.

См. также: [Архитектура решения](integrations/architecture.md).

## Контекст запроса

**Контекст запроса** — набор данных текущего входящего запроса: исходные данные,
текст сообщения или команды, идентификаторы чата и инициатора, сведения о сессии
и результат проверки доступа.

См. также: [Архитектура решения](integrations/architecture.md).

## Сессия пользователя

**Сессия пользователя** — состояние взаимодействия пользователя с ботом в
рамках конкретного чата. Она хранит сведения о доступе, аутентификации и текущем
шаге диалога.

См. также: [Управление доступом](integrations/access-control.md).

## Профиль пользователя мессенджера

**Профиль пользователя мессенджера** — внутренняя запись РИМ, которая связывает
внешнего пользователя мессенджера с системой и при необходимости с пользователем
информационной базы.

См. также: [Управление доступом](integrations/access-control.md).

## Аутентификация

**Аутентификация** — процесс подтверждения личности пользователя перед
предоставлением доступа к боту. В РИМ могут использоваться пароль, пользователь
информационной базы или одноразовый код.

См. также: [Управление доступом](integrations/access-control.md).

## Способ доступа

**Способ доступа** — настройка бота, определяющая правила допуска пользователя
к прикладной обработке входящих запросов.

См. также: [Управление доступом](integrations/access-control.md).

## Long polling

**Long polling** — активный способ подключения, при котором РИМ самостоятельно
запрашивает новые события у сервиса мессенджера.

См. также: [Создание бота](bots/create-bot.md).

## Webhook

**Webhook** — пассивный способ подключения, при котором мессенджер отправляет
события на HTTP-адрес РИМ.

См. также: [Создание бота](bots/create-bot.md).
