**РИМ** — это расширение для **1С:Предприятия**, предназначенное для интеграции мессенджеров и автоматизации работы с ними.

РИМ предоставляет единый интерфейс для подключения к различным мессенджерам, получения и отправки сообщений, а также создания ботов для автоматизированной обработки сообщений, команд и событий.

В настоящий момент РИМ поддерживает Telegram и ВКонтакте и может быть расширен для работы с другими мессенджерами.

!!! warning "Проект находится в стадии разработки"

    Документация подготовлена для версии РИМ `2.0.0.0`.

    Функциональность и API могут изменяться.

    Документация носит предварительный характер и может быть неполной.

---

### 📐 Концепция

РИМ предоставляет единый слой взаимодействия с различными мессенджерами, скрывая особенности их API и форматов данных.

В основе РИМ лежат:

- единый интерфейс для получения и отправки сообщений;
- собственный механизм аутентификации пользователей;
- управление и хранение пользовательских сессий;
- поддержка контекстного взаимодействия.

На основе этих механизмов создаётся прикладная логика ботов для автоматизированной обработки сообщений, команд и событий.

---

### ⚙️ Возможности

РИМ предоставляет следующие возможности:

- подключение различных мессенджеров;
- получение и отправка сообщений;
- обработка входящих команд и событий;
- создание ботов с прикладной логикой;
- управление сессиями и доступом пользователей.

---

### 📋 Требования и совместимость

Для работы РИМ необходимы:

- платформа `1С:Предприятие 8.3.27.1936` или более поздней версии;
- клиент-серверный вариант работы информационной базы;
- наличие необходимых компонентов Библиотеки стандартных подсистем, включая подсистему управления пользователями.

Файловый вариант работы информационной базы не поддерживается.

!!! warning "Особенности совместимости"

    РИМ не привязан к конкретной прикладной конфигурации и может использоваться в конфигурациях, содержащих необходимые компоненты Библиотеки стандартных подсистем.

    Работа на более ранних версиях платформы, а также в других конфигурациях и версиях БСП отдельно не проверялась.

Тестирование выполнялось в следующем окружении:

| Компонент | Версия |
|---|---|
| 1С:Предприятие | `8.3.27.1936` |
| Управление торговлей | `11.5.25.109` |
| Библиотека стандартных подсистем | `3.1.11.392` |
