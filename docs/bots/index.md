# Введение: Боты

Боты в РИМ связывают модель бота с конкретной интеграцией мессенджера.

Бот определяет, какая модель бота должна обрабатывать входящие запросы и через какую интеграцию РИМ должен получать и отправлять сообщения.

!!! info "Разделение ответственности"

    Интеграция определяет, как взаимодействовать с мессенджером.

    Модель бота определяет, как обрабатывать входящие запросы.

    Бот связывает модель бота с интеграцией в конкретный работающий экземпляр.

---

## Бот

**Бот** — это объект РИМ, представляющий конкретный экземпляр бота.

В настройках бота указываются:

- модель бота;
- параметры интеграции мессенджера;
- способ доступа пользователей;
- другие параметры работы конкретного экземпляра.

Бот связывает прикладную модель бота с интеграцией выбранного мессенджера. В рамках обработки запросов РИМ предоставляет модели бота единый программный интерфейс, позволяющий получать данные запроса, работать с контекстом и формировать исходящие сообщения.

За счёт этого модель бота работает через механизмы РИМ и не взаимодействует напрямую с API мессенджера.

## Модель бота

**Модель бота** — это реализация прикладной логики, определяющая поведение бота.

Модель бота обрабатывает входящие запросы, команды и события, использует данные контекста и формирует ответы пользователю.

Модель бота не содержит параметров подключения к мессенджеру и не зависит от конкретной интеграции. Одна модель бота может использоваться несколькими ботами, подключёнными к разным мессенджерам.

Например, одна модель бота для обработки обращений может использоваться двумя ботами:

- ботом, подключённым к Telegram;
- ботом, подключённым к ВКонтакте.

В обоих случаях модель бота получает запросы через единый программный интерфейс РИМ.

## Интеграция мессенджера

**Интеграция мессенджера** обеспечивает взаимодействие РИМ с API конкретного мессенджера.

Она отвечает за получение внешних событий, преобразование данных, отправку сообщений и работу с параметрами подключения.

Интеграция не определяет поведение бота и не содержит его прикладную логику.

Подробнее устройство интеграционного механизма описано в разделе [Интеграции](../integrations/index.md).

## Связь компонентов

| Компонент | Ответственность |
|---|---|
| Бот | Связывает модель бота с параметрами интеграции и определяет настройки конкретного экземпляра |
| Модель бота | Содержит прикладную логику обработки входящих запросов |
| Интеграция мессенджера | Обеспечивает обмен данными с API конкретного мессенджера |

При обработке входящего события взаимодействие компонентов выглядит следующим образом:

1. Интеграция получает событие от мессенджера и передаёт его в РИМ.
2. РИМ определяет бота, которому предназначен входящий запрос.
3. По настройкам бота РИМ определяет используемую модель бота.
4. РИМ подготавливает контекст и передаёт входящий запрос модели бота.
5. Модель бота обрабатывает входящий запрос и формирует исходящие сообщения через программный интерфейс РИМ.
6. РИМ помещает исходящие сообщения в очередь отправки, после чего передаёт их интеграции для отправки пользователю.
